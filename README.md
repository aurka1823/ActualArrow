# ActualArrow

Сборка модов ActualArrow для Broken Arrow и список сборок для лаунчера ActualArrow.

- **Релизы** этого репозитория — сборка ActualArrow: файл `.bamod` в каждом релизе. Лаунчер берёт последний релиз.
- **`catalog.json`** — список сборок, которые лаунчер показывает в выпадающем списке. Новая сборка появляется у игроков
  без обновления лаунчера.

## Как добавить сборку в список

Нужен публичный репозиторий на GitHub, в каждом релизе которого лежит `.bamod` (сборка: `mod.json` и папки `Mods/`,
`Plugins/`, `UserLibs/`, `UserData/`). Добавьте в `catalog.json` запись:

```json
{
  "id": "автор.сборка",
  "name": "Название для игроков",
  "repo": "владелец/репозиторий",
  "author": "Автор",
  "description": "Одна строка о сборке"
}
```

`id` — тот же, что в `mod.json` сборки. Чтобы у сборки были свои деки, положите в неё мод `DeckSlots.dll` (папка `Mods/`).
